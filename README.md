# 🚀 Mini Hackathons

This repository gathers a collection of projects developed during personal mini-hackathons.

The goal of these challenges is to practice software development by building functional applications within a limited timeframe (usually between 2 and 8 hours). Each project aims to solve a specific problem using an MVP (Minimum Viable Product), prioritizing development speed, decision-making, and delivering results.

## 🎯 Objectives

* Improve Full Stack development skills.
* Practice designing and building MVPs.
* Experiment with new technologies and architectures.
* Strengthen the ability to develop under time constraints.
* Create a portfolio of small yet functional projects.

## 📚 Philosophy

Each project is developed within a limited timeframe to simulate a hackathon, focusing on:

* Rapid planning.
* Iterative development.
* Functionality over perfection.
* Clean and maintainable code.
* Continuous learning.
